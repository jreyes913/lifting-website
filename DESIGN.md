# Design System Specification: Proximal50 Website

## 1. Brand Identity & Aesthetic
* **Theme:** Clinical-Industrial / Modern Wellness
* **Visual Strategy:** High-contrast, minimalist, action-oriented.
* **Key Elements:** Heavy use of negative space, low-key (dark) photography, and orange accentuation.

## 2. Color Palette (Hierarchy)
1.  **Primary (Base):** #FFFFFF (Pure White)
    * *Usage:* Backgrounds, primary UI containers, button text.
2.  **Secondary (Action):** #F28C38 (Brand Orange)
    * *Usage:* Logo, CTA buttons, icons, high-level headers.
3.  **Tertiary (Text):** #333333 (Charcoal Gray)
    * *Usage:* Primary body text, section sub-headers.
4.  **Accent (Details):** #707070 (Medium Gray)
    * *Usage:* Navigation links, footer metadata, secondary labels.

## 3. Typography System (Hierarchy)
* **Font Family:** Modern Geometric Sans-Serif (e.g., Montserrat, Roboto, or Lato).

### Level 1: Hero Headlines (H1)
* **Style:** All-Caps, Bold (700)
* **Size:** 64px - 72px
* **Color:** White (#FFFFFF) or Orange (#F28C38)
* **Function:** Primary Value Propositions.

### Level 2: Section/Category Headers (H2)
* **Style:** All-Caps, Semi-Bold (600)
* **Size:** 24px - 28px
* **Color:** Charcoal (#333333) or Orange (#F28C38)
* **Function:** Feature labels and location titles.

### Level 3: Navigation & Interface
* **Style:** Sentence Case, Medium (500)
* **Size:** 14px - 16px
* **Color:** Gray (#707070)
* **Function:** Global navigation and utility links.

### Level 4: Body Copy
* **Style:** Sentence Case, Regular (400)
* **Size:** 16px - 18px
* **Line-Height:** 1.6 (High Readability)
* **Color:** Charcoal (#333333)
* **Function:** Narrative text and descriptions.

## 4. UI & Layout Components
* **Buttons:** Rounded corners (pill-style). Primary CTAs use "Ghost" or "Solid" white against dark backgrounds.
* **Icons:** Circular orange containers with white flat-style glyphs.
* **Imagery Style:** Photography utilizes heavy shadows (Low-Key) to provide natural contrast for overlaying text without gradient masks.
* **Footer:** Multi-column layout with strict vertical alignment for multiple locations and contact data.
